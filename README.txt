DETektif Cilik — Absensi PJJ Kelas 6B v1

Isi:
- index.html: halaman absensi siswa
- guru.html: dashboard guru
- css/style.css: tema Detektif Cilik
- js/app.js: logika absensi
- assets/: folder aset

Daftar siswa: 28 siswa Kelas 6B.

Fitur v1:
- Pilih nama siswa dan mapel
- Status Hadir/Izin/Sakit/Alpa
- Upload/preview foto bukti kehadiran
- Waktu otomatis
- Dashboard guru
- Filter tanggal dan mapel
- Lihat foto bukti
- Export CSV
- Responsif HP

PENTING:
Versi v1 adalah prototype lokal. Data tersimpan di localStorage browser, sehingga belum tersinkron antar-HP.
Untuk versi produksi multi-perangkat, diperlukan backend/database dan object storage (misalnya Supabase/Firebase) serta autentikasi guru.
